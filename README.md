# Cloud-misconfiguration-hunt-and-remediation-AWS-Azure-IAM-and-storage-
A cloud security project focused on identifying, analyzing, and remediating common security misconfigurations in AWS and Azure environments
**Create → Misconfigure → Hunt → Fix → Verify → Document**

The goal is to demonstrate how cloud security misconfigurations can be identified and corrected using cloud security best practices.

---

## Goals

The goals of this project are to:

- Identify common security misconfigurations in AWS and Azure environments.
- Understand the security risks associated with excessive permissions and publicly accessible storage.
- Apply the principle of least privilege to cloud IAM and RBAC.
- Secure cloud storage by removing unnecessary public access.
- Configure appropriate storage protection and encryption.
- Apply remediation steps to reduce security risks.
- Verify that each remediation successfully corrected the identified issue.
- Gain experience with AWS and Azure cloud security tools.
